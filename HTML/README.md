# SK GOPI VFX

Professional Photo & Video Editing Website

## Requirements

- PHP 8+
- MySQL
- Apache (XAMPP)

## Installation

1. Copy project into htdocs
2. Create database `sk gopi_vfx`
3. Import `sk gopi_vfx.sql`
4. Update `db.php`
5. Start Apache & MySQL
6. Open http://localhost/gopi-vfx
